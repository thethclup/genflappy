# GenFlappy 🐦⛓️

**GenFlappy** is an AI-powered blockchain game running on the **GenLayer** network. It puts a Web3/Validator spin on the classic Flappy Bird concept by combining real-time gameplay with LLM-driven Intelligent Contracts (GenVM).

In GenFlappy, you play as a "Validator Bird" navigating through consensus node "pipes." Every action, from the theme of the flight to the final score evaluation, is narrated and judged dynamically by AI running directly on-chain!

## 🌟 Key Features

* **AI-Generated Game Themes:** When you start a game, the GenLayer smart contract triggers an LLM to generate a unique, dramatic flight theme based on blockchain concepts.
* **Mid-Flight AI Verdicts (Checkpoints):** When you request a boost, an on-chain AI judge decides your fate based on your performance, providing a blockchain-themed reason.
* **Intelligent Flight Reports & Anti-Cheat:** Hitting a pipe triggers the final evaluation. The smart contract evaluates your score, checks for physical impossibilities using AI semantic analysis (e.g., passing 100 pipes in 2 seconds), and catches cheaters. Honest players get a poetic flight report.
* **Semantic Validator Consensus:** The Equivalence Principle validators don't just check JSON shapes—they semantically analyze the leader's generated text to ensure it makes sense and follows the prompt instructions!
* **On-Chain Leaderboard:** A global `TreeMap` state stores player high scores and displays the top 10 validators of the network, protected by `msg.sender` verification.

## 🛠️ Tech Stack

* **Frontend:** React 18, Vite, TypeScript, Tailwind CSS
* **Blockchain/Smart Contracts:** Python (GenLayer SDK / GenVM)
* **Web3 Integration:** `genlayer-js` SDK via Browser Injection (MetaMask)
* **AI Tooling:** GenLayer's Non-Deterministic Execution (`gl.nondet.exec_prompt`)

## 🚀 Getting Started (GitHub & Local)

If you have cloned this repository from GitHub, you will need to set up your environment variables before running the game.

### 1. Install Dependencies
```bash
npm install
```

### 2. Environment Setup (.env.local)
We use a `.env.local` file to store the smart contract address. This file is ignored by Git, so you must create it locally.

Copy the example environment file:
```bash
cp .env.example .env.local
```

Then edit `.env.local` and add the live GenFlappy contract address, for example:
```env
VITE_CONTRACT_ADDRESS="0x5F5E09Ae44a00562B52B983fdFfd69f423e39a3e"
```

### 3. Run the Dev Server
```bash
npm run dev
```
Make sure you have a Web3 wallet (like MetaMask) installed and connected to the GenLayer Testnet to play!

### 4. (Optional) Deploy Your Own Contract
If you want to deploy your own instance of the GenFlappy intelligent contract:

```bash
# Setup network and account
npx genlayer network set testnet-bradbury
npx genlayer account create --name flappy-deployer
npx genlayer account use flappy-deployer

# Deploy the contract
npx genlayer deploy --contract contracts/genflappy.py
```
Then update the `VITE_CONTRACT_ADDRESS` in your `.env.local` with the new address.

## 📜 Smart Contract Highlights (`contracts/genflappy.py`)

The contract uses GenLayer's "Equivalence Principle" via `gl.vm.run_nondet_unsafe` to reach a decentralized consensus on output generated by internal LLMs. 

* `leader_fn()` queries the LLM for a creative blockchain story or judgement.
* `validator_fn(leader_result)` strictly validates the output formatting (e.g., enforcing valid JSON dictionaries with expected exact keys like `verdict`, `amount`, and `reason`).
